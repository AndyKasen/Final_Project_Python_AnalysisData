# Анализ данных резюме с hh.ru

## Описание проекта
Проект по анализу данных о соискателях с сайта hh.ru. 
Исследуем распределение зарплат, возраста, опыта работы.

## Структура проекта
- `Final_Project_PY.ipynb` - основной ноутбук с анализом
- `plots/` - папка с графиками
- `data/` - **данные не включены в репозиторий** (слишком большие)

## Данные
CSV файлы (455 MB) доступны по ссылкам:
1. [ExchangeRates.csv](https://drive.google.com/file/d/1mRrwB3LlDqEJvz4OhtIlsNgI8cYmHrw9/view?usp=sharing) - курсы валют
2. [hh_database.csv](https://drive.google.com/file/d/1mRrwB3LlDqEJvz4OhtIlsNgI8cYmHrw9/view?usp=sharing) - база резюме

## Как запустить
1. Скачайте данные по ссылкам выше
2. Поместите в папку `data/`
3. Запустите `Final_Project_PY.ipynb` в Jupyter
